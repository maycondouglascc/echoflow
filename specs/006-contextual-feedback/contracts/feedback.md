# POST /api/feedback

Origin must exactly match the trusted NEXT_PUBLIC_SITE_URL origin (never a forwarded/client-supplied Host). Same-origin authenticated multipart/form-data. `metadata` JSON: {id UUID, message 10..5000 trimmed characters, pagePath, capturedAt ISO, viewport:{width,height}, navigation:[{path,action,at}]}. Optional `screenshot` PNG <=2 MiB, dimensions <=1920×1440. Body <=2 MiB +64 KiB; metadata <=16 KiB. Allowed path /home or /scenarios/[a-z0-9-]{1,80}; actions page/select-phrase/select-voice/listen-reference/replay-word/record/stop-recording/compare/next-phrase. Event time chronological, within five minutes before capture; capture within 24h before submission for retry.

201 {id} newly persisted; 200 {id} same payload retried; 400 invalid; 401 missing/expired session; 403 foreign/missing Origin; 409 identifier reused with different payload; 413 oversized; 503 storage/database unavailable. Private no-store responses, generic errors, no credentials/internal errors. Backend authenticates and validates before writes; cleans only newly uploaded image on failed insert. Tests cover idempotency, cleanup, wrong-owner, invalid PNG/body/origin and upload failure.
