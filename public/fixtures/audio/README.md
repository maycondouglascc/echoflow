# Reference audio fixtures

These three files are generated locally from the canonical phrase text in `src/lib/fixtures/introducing-yourself.json`. They are static same-origin WAVs; the app, build, CI and browser tests do not run a speech synthesizer.

## Generation record

- Engine/API: eSpeak NG 1.52.0 C API, called through Python's standard-library `ctypes`.
- Local Ubuntu package versions: `libespeak-ng1` and `espeak-ng-data` `1.52.0+dfsg-5build1`.
- Voice: `en-us`.
- Rate: 150 words per minute.
- Random seeds: 20260926, 20260927 and 20260928, derived from `20260925 + phrase order`.
- Output: mono, signed 16-bit PCM WAV at 22,050 Hz.
- Regenerate offline with `scripts/generate-reference-audio.sh` after installing the eSpeak NG library and its voice data. The helper uses the public synthesis API and contains no extra Python package dependency.
- The upstream eSpeak NG source and voice data are GPL-3.0-or-later ([upstream license](https://github.com/espeak-ng/espeak-ng/blob/master/COPYING), [voice documentation](https://github.com/espeak-ng/espeak-ng/blob/master/docs/voices.md)). The project does not bundle the library or voice data. GPL section 2 says output is covered only if its content constitutes a covered work; this note does not resolve the generated WAVs’ redistribution status. These files are included for this local prototype only. Review the applicable terms before publishing or sharing them.
