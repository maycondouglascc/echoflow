# EchoFlow

**Practice English speaking the way your brain learns best — by listening and repeating.**

EchoFlow is a Next.js web app that teaches English speaking fluency through the **shadowing technique**: users listen to native-sounding audio and immediately repeat it. The app records your voice, plays it back alongside the reference, and tracks progress over time.

## Tech Stack

- Next.js 14+ (App Router) · TypeScript · Tailwind · shadcn/ui
- Supabase (Auth, Database, Storage)
- ElevenLabs (TTS) · OpenAI Whisper (Transcription)
