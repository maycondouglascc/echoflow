# EchoFlow Context

## Glossary

- **Phrase**: Canonical written utterance that a learner practices. A phrase keeps the content category it originated from, even when included in a cross-category voice sample set.
- **Audio model**: A named speech-synthesis model that produces a reference sample from phrase text.
- **Voice**: The speaker identity supported by an audio model; the model/voice pair identifies a comparison choice.
- **Audio variant**: One phrase rendered by one model/voice pair, with a specific file format and provenance.
- **Reference audio**: A curated audio variant played before or alongside the learner's practice flow.
- **Archived baseline**: A retained historical audio variant that is cataloged but not offered as an active learner choice.
- **Generation record**: The available metadata of one synthesis operation, including its provider request identifier and generation time.
- **Personal recording**: The learner's own temporary capture, associated with a phrase only during the current page session.
